## About OGN - Open Gliding Network
Open Gliding Network (OGN) is a community-driven, open-source aviation project that builds and maintains a global, unified tracking platform for gliders, paragliders, drones, and other aircraft equipped with FLARM, OGN trackers, ADS-L devices and other compatible transmitters. It uses a network of low-cost ground receivers and APRS servers to collect real-time position data, which is freely accessible for live tracking, mapping, flight logging, search-and-rescue support, and safety applications. The project emphasizes open protocols and broad participation from volunteers, clubs, and developers, aiming to expand coverage and improve situational awareness in airspace where conventional radar often doesn’t show lighter aircraft.
